# 개 근육 첫걸음

반려동물과 학생용 수업 웹페이지(70~80분 1차시). 개 겉근육 8개를 이름 풀기 → 위치·결 방향 → 찾기 게임 → 퀴즈 → 복습 카드로 반복한다.

- 주소: https://bsead.github.io/dogmuscle/
- 페이지: `docs/index.html` 한 파일 (근육 자료 `M` 배열, 그림 위 근육 영역 `poly`, 결 방향 `fa`→`fb`)
- 그림: Sisson(1910) Fig. 230, 퍼블릭 도메인 (Wikimedia Commons)
- 한글 용어: 수의학용어 검색 term.anidap.net (VT). `src/anidap.py 용어...`로 조회
- 이는곳·닿는곳·하는 일: NC State 수의대 근골격 실습서(Gerard & Cobb)
- 근육 영역 좌표는 그림(2010×1190) 기준. 고친 뒤 브라우저로 '8개 한꺼번에'를 눌러 겹침을 확인한다.
